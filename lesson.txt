Navegador → Controller → Service → Repository → PostgreSQL
Navegador ← JSON ← DTO ← Mapper ← Service ← Repository

De BASE DE DATOS a PAYLOAD de salida 
PostgreSQL
  → Repository devuelve Project (objeto Java)
  → Service coordina la operación
  → Mapper convierte Project en ProjectResponse
  → Controller devuelve el resultado (De DTO a JSON)
  → Spring MVC y Jackson lo serializan a JSON (en Controller)

* DTO: Un DTO (Data Transfer Object) es un objeto pensado para transportar datos entre partes del sistema o a través de la API. ProjectRequest representa datos de entrada; ProjectResponse, datos de salida.
* Bean Validation: mecanismo que comprueba reglas declaradas en los campos del DTO.
* Controller Advice: componente Spring que centraliza el manejo de excepciones de los Controllers.
* @ExceptionHandler: indica qué método puede manejar cierto tipo de excepción.
* Restricción UNIQUE: regla de la base de datos que impide valores duplicados en una columna, como el slug.
* Código HTTP: comunica el resultado de la petición: 400 entrada inválida, 404 recurso ausente y 409 conflicto con el estado existente.
